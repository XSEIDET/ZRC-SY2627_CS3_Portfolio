# Activity 2 Reflection: The `@property` Decorator

## Question
How does using `@property` make your code easier to read compared to using traditional `get_` and `set_` methods?

## Answer
Using `@property` makes code much cleaner and easier to read because it allows you to treat getters and setters like regular attributes instead of traditional methods[cite: 8]. Because you don't need to use awkward parentheses when accessing or updating values, the syntax looks and flows much more naturally—just like working with normal variables[cite: 8]. It essentially gives you a smoother, more intuitive way to interact with your classes without losing any of the security and data protection behind the scenes[cite: 8].
