## Activity 2: Follow-Along Challenge

**1. The Blueprint Concept**
It’s called a blueprint because it sets up the basic structure and rules for other classes to follow. You can't use it on its own, so you have to build specific child classes from it first.

**2. The "Must-Have" Rule**
- [ ] Change their variable names.
- [x] Implement their own version of that specific method.
- [ ] Delete the parent class.

**3. Safety First**
Python will block it and give a `TypeError` because you can't create an object directly from an abstract class.
